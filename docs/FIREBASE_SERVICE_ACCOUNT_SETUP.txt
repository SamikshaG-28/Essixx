Fix: "Missing Firebase service account" on Essixx (Hostinger)
=============================================================

This error means PHP cannot read/write Firestore on the server. Cashfree keys alone are not enough.

This is configured on ESSIXX ONLY (Hostinger). UrbanCart does NOT upload a service account.


STEP 1 — Download JSON (one-time, free)
---------------------------------------

1. Open https://console.firebase.google.com
2. Select project: urbancart-cc45c
3. Click gear icon → Project settings
4. Tab: Service accounts
5. Click "Generate new private key" → Confirm
6. A file downloads (e.g. urbancart-cc45c-firebase-adminsdk-xxxxx.json)


STEP 2 — Place file on Essixx (local + server)
----------------------------------------------

Rename or copy the downloaded file to:

  public/api/cashfree/service-account.json

Same folder as create-session.php.


STEP 3 — Set api/cashfree/.env
------------------------------

File: public/api/cashfree/.env

Must include:

  CASHFREE_ENV=production
  CASHFREE_CLIENT_ID=<your cashfree app id>
  CASHFREE_CLIENT_SECRET=<your cashfree secret>
  PAYMENT_RETURN_URL=https://essixx.com/payment/return
  FIREBASE_PROJECT_ID=urbancart-cc45c
  FIREBASE_SERVICE_ACCOUNT_PATH=service-account.json

Alternative (single line instead of JSON file):

  FIREBASE_SERVICE_ACCOUNT_JSON={"type":"service_account","project_id":"urbancart-cc45c",...entire json on one line...}

Prefer service-account.json file — easier.


STEP 4 — Upload to Hostinger after npm run build
-------------------------------------------------

Upload BOTH to public_html/api/cashfree/:

  - .env
  - service-account.json
  - all .php and lib/ files

If you only upload dist/ without service-account.json, Pay will fail with this error.


STEP 5 — Verify file permissions (Hostinger)
--------------------------------------------

- service-account.json should NOT be public in browser ( .htaccess blocks it )
- PHP must be able to read the file (644 is usually fine)


NOT a Firebase plan upgrade
-----------------------------

Service account keys are free. Same Firebase project UrbanCart already uses (urbancart-cc45c).


Still failing?
--------------

- Confirm filename matches FIREBASE_SERVICE_ACCOUNT_PATH exactly
- Confirm JSON is valid (opens in editor, has "private_key", "client_email")
- Re-upload after npm run build — Vite copies public/api/cashfree/ into dist/
