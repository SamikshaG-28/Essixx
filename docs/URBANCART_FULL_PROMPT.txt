URBANCART — ALWAYS DO THIS ON EVERY CHECKOUT
--------------------------------------------------------------------------------

STEP 1 — Create / update Firestore document orders/{orderId}
----------------------------------------------------------

Required fields:

  sourceSite:         "urbancart"
  paymentMethod:      "cashfree"
  status:             "payment_processing"   (or "awaiting_payment")
                        NEVER "paid" before Essixx confirms payment
  amount:             number                 (e.g. 29)
  currency:           "INR"
  userName:           string
  userEmail:          string
  items:              array                  [{ name, quantity, productId? }]
  address:            map                    { name, addressLine, city, stateName, pincode, phone }
  returnUrlSuccess:   "https://urbancart.fun/#/payment-success?order=" + orderId
  returnUrlFailure:   "https://urbancart.fun/#/payment-failed?order=" + orderId

Optional but recommended:

  createdAt, updatedAt, cart metadata you already store


STEP 2 — Create Cashfree payment session (UrbanCart server-side ONLY)
---------------------------------------------------------------------

Cashfree secret (x-client-secret) and app id (x-client-id) stay on UrbanCart
only. Never put them in Essixx React build or urbancart.fun frontend.

API:

  POST https://api.cashfree.com/pg/orders
  (sandbox: https://sandbox.cashfree.com/pg/orders)

Headers:
  Content-Type: application/json
  x-api-version: 2023-08-01
  x-client-id: <YOUR_CASHFREE_APP_ID>
  x-client-secret: <YOUR_CASHFREE_SECRET>

Request body example:

  {
    "order_id": "UC-{orderId}",
    "order_amount": 29,
    "order_currency": "INR",
    "customer_details": {
      "customer_id": "customer@email.com",
      "customer_name": "Full Name",
      "customer_email": "customer@email.com",
      "customer_phone": "8552965569"
    },
    "order_meta": {
      "return_url": "https://essixx.com/payment/return?orderId={orderId}"
    },
    "order_note": "UrbanCart order {orderId}"
  }

customer_phone: 10-digit Indian mobile (digits only preferred).

Response: save these fields on the SAME Firestore order document:

  paymentSessionId:  response.payment_session_id
  cashfreeOrderId:   "UC-" + orderId
  cashfreeEnv:       "production"    (or "sandbox" for testing)

Wait until Firestore write completes before redirect.


STEP 3 — Redirect customer to Essixx
------------------------------------

Only orderId is required in the URL:

  window.location.href = "https://essixx.com/checkout?orderId=" + orderId;

Use encodeURIComponent(orderId) if needed.

Do NOT open Cashfree checkout on urbancart.fun domain.


STEP 4 — UrbanCart return pages (REQUIRED)

Route: /#/payment-success?order={orderId}

--------------------------------------------------------------------------------
FIRESTORE SECURITY RULES (Firebase Console — free Spark plan OK)
--------------------------------------------------------------------------------

Project: urbancart-cc45c → Firestore → Rules

Allow read on orders for checkout. Allow Essixx to update payment fields only:

  rules_version = '2';
  service cloud.firestore {
    match /databases/{database}/documents {
      match /orders/{orderId} {
        allow read: if true;
        allow create: if true;
        allow update: if request.resource.data.diff(resource.data).affectedKeys()
          .hasOnly([
            'status',
            'cashfreePaymentStatus',
            'cashfreePaymentId',
            'cashfreeOrderId',
            'paymentFailureReason',
            'paidAt',
            'updatedAt'
          ]);
      }
    }
  }

Tighten with auth / sourceSite checks in production when ready.

EXAMPLE: URBANCART REDIRECT HELPER (JavaScript)
--------------------------------------------------------------------------------

async function payOnEssixx(orderId, orderPayload, cashfreeCredentials) {
  const orderRef = doc(db, 'orders', orderId)

  // 1) Save order
  await setDoc(orderRef, {
    ...orderPayload,
    sourceSite: 'urbancart',
    paymentMethod: 'cashfree',
    status: 'payment_processing',
    returnUrlSuccess: `https://urbancart.fun/#/payment-success?order=${orderId}`,
    returnUrlFailure: `https://urbancart.fun/#/payment-failed?order=${orderId}`,
  }, { merge: true })

  // 2) Create Cashfree session — call YOUR server, not browser with secret
  const session = await fetch('https://urbancart.fun/api/cashfree/create-order', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ orderId, ...orderPayload }),
  }).then((r) => r.json())

  // 3) Save session on order
  await updateDoc(orderRef, {
    paymentSessionId: session.payment_session_id,
    cashfreeOrderId: `UC-${orderId}`,
    cashfreeEnv: 'production',
  })

  // 4) Redirect to Essixx
  window.location.href = `https://essixx.com/checkout?orderId=${encodeURIComponent(orderId)}`
}

EXAMPLE: URBANCART SERVER — CREATE CASHFREE ORDER (Node.js)
--------------------------------------------------------------------------------

// UrbanCart backend only — NOT on Essixx

app.post('/api/cashfree/create-order', async (req, res) => {
  const { orderId, amount, userEmail, userName, phone } = req.body

  const response = await fetch('https://api.cashfree.com/pg/orders', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'x-api-version': '2023-08-01',
      'x-client-id': process.env.CASHFREE_CLIENT_ID,
      'x-client-secret': process.env.CASHFREE_CLIENT_SECRET,
    },
    body: JSON.stringify({
      order_id: `UC-${orderId}`,
      order_amount: Number(amount),
      order_currency: 'INR',
      customer_details: {
        customer_id: String(userEmail).slice(0, 80),
        customer_name: userName,
        customer_email: userEmail,
        customer_phone: String(phone).replace(/\D/g, '').slice(-10),
      },
      order_meta: {
        return_url: `https://essixx.com/payment/return?orderId=${encodeURIComponent(orderId)}`,
      },
    }),
  })

  const data = await response.json()
  if (!response.ok) return res.status(500).json({ error: data.message })

  res.json({
    payment_session_id: data.payment_session_id,
    cashfree_order_id: data.order_id,
  })
})


--------------------------------------------------------------------------------
END-TO-END FLOW
--------------------------------------------------------------------------------

  1. Customer checks out on UrbanCart
  2. UrbanCart writes orders/{orderId} in Firestore
  3. UrbanCart server calls Cashfree → gets paymentSessionId → saves on order
  4. UrbanCart redirects to https://essixx.com/checkout?orderId=...
  5. Essixx loads order, auto-opens Cashfree with paymentSessionId
  6. Customer pays on Cashfree (essixx.com domain)
  7. Cashfree redirects to https://essixx.com/payment/return?orderId=...&order_status=...
  8. Essixx sets Firestore status paid or payment_failed
  9. Essixx redirects to returnUrlSuccess or returnUrlFailure on urbancart.fun
  10. UrbanCart success page reads status === "paid" and completes UX

--------------------------------------------------------------------------------
TROUBLESHOOTING
--------------------------------------------------------------------------------

"Missing paymentSessionId on order"
  → UrbanCart did not run Cashfree create-order API or did not save session on Firestore

"Order not found"
  → Wrong orderId or wrong Firebase project (must be urbancart-cc45c)

"Permission denied" on Firestore update from Essixx
  → Update Firestore rules (see section above)

Cashfree does not open on Essixx
  → paymentSessionId invalid/expired; create new session and redirect again

Essixx shows paid but UrbanCart does not
  → UrbanCart success page must read same Firestore project and orderId
